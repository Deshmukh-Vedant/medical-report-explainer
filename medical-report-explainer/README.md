# 🩺 AI Medical Report Explainer & Risk Predictor

**"Understand Your Medical Reports in Simple Language with AI & Machine Learning Risk Prediction"**

An end-to-end medical web application that lets users upload blood test reports, pathology reports, CBC, lipid profiles, liver/kidney function tests, thyroid panels, and diabetes reports — providing clear, simple-language explanations with Google Gemini AI alongside machine learning risk classification.

> ⚠️ **Disclaimer:** All explanations and predictions generated by this application are strictly for educational purposes and do **NOT** constitute medical advice, diagnosis, or clinical evaluation. Always consult a qualified physician.

## 🧩 Key Features

### 1. Complete & Hardened Authentication System
- **Registration & Login**: Secure account creation with email validation and strong password hashing.
- **Forgot Password Workflow**: Single-use, time-limited (30-minute) tokens hashed via HMAC-SHA256 in the database.
- **Change Password**: Authenticated password rotation requiring current password verification.
- **Profile Management**: Editable display names, account stats (reports uploaded and analysed), and session control.
- **Email Service**: Asynchronous SMTP delivery (`aiosmtplib`) for reset links and account notices, with automatic console fallback for local development.

### 2. Machine Learning Risk Prediction
- **10 Core Lab Features**: Hemoglobin, WBC count, platelets, glucose, creatinine, ALT (SGPT), AST (SGOT), total protein, HbA1c, and cholesterol.
- **Smart Parameter Extractor**: Regex-based clinical parser with automatic unit conversion (e.g. cells/µL to $10^3/\mu\text{L}$) and sanity-range boundaries.
- **Random Forest Classifier**: Trained on 12,000 clinically calibrated samples with missing-value imputation (`SimpleImputer(strategy="median")`).
- **Dashboard ML Card**: Displays predicted risk level (Low, Moderate, High), confidence score meter, extracted values grid, and imputation notes.
- **Interactive Tools**: Diabetes and heart risk calculators wired directly to `POST /predict/manual`.

### 3. Medical Report Processing & AI Explanation
- **Multi-Engine PDF Extraction**: Digital extraction via `pdfplumber`, rendering via `PyMuPDF`, and OCR fallback via `pytesseract`.
- **Gemini 2.5 Flash Analysis**: Structured explanations, abnormal flag detection, lifestyle/diet recommendations, and doctor consultation advice.
- **Offline Fallback**: Resilient offline analysis mechanism ensuring reports can always be inspected even without an external API connection.
- **Bilingual Support**: Instant toggle between English and Marathi explanations.
- **Audio Playback**: Web Speech API integration to read report findings aloud.

## ⚙️ Installation & Setup

### 1. Clone & Set Up Virtual Environment

```bash
cd medical-report-explainer
python -m venv venv

# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Configure Environment Variables

Create or update `backend/.env`:

```env
# Gemini API Key (from https://aistudio.google.com/app/apikey)
GEMINI_API_KEY=your_gemini_api_key_here

# JWT Authentication
JWT_SECRET_KEY=change_this_to_a_secure_random_key_in_production
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60

# Password Reset & Base URL
RESET_TOKEN_EXPIRE_MINUTES=30
APP_BASE_URL=http://localhost:5500

# Email Delivery (leave blank for development console mode)
SMTP_HOST=
SMTP_PORT=587
SMTP_USERNAME=
SMTP_PASSWORD=
EMAIL_FROM=noreply@medexplain.ai

# Database & Limits
DATABASE_URL=sqlite:///./medical_reports.db
MAX_UPLOAD_MB=20
```

### 3. Train or Retrain the ML Model (Optional)

The trained model is pre-generated at `backend/ml/models/lab_risk_classifier.pkl`. To retrain:

```bash
cd backend
python -m ml.train
```

## ▶️ Running the Application

### Start the FastAPI Backend

```bash
cd backend
uvicorn main:app --reload --port 8000
```
- API Docs: `http://127.0.0.1:8000/docs`
- Health check: `http://127.0.0.1:8000/`

### Start the Frontend

Open a new terminal window:

```bash
cd frontend
python -m http.server 5500
```
Open `http://127.0.0.1:5500/` in your browser.
